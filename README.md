# Auto-Insurance Risk Analytics & Predictive Modeling

## Business Context & Objectives
As part of AlphaCare Insurance Solutions (ACIS), this analytics system analyzes historical auto-insurance data across South Africa to uncover low-risk customer profiles, optimize strategic marketing premium targets, and construct reproducible analytics-driven pipelines.

## Repository Layout
- `data/`: Managed via DVC (contains `raw/` and `processed/` stages)
- `notebooks/`: Exploratory Data Analysis (EDA) and visualization playbooks
- `src/`: Production-ready, modular data cleaning and engineering Python modules
